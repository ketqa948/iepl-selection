## 先弄明白：IEPL、IPLC、IX 和普通 BGP 中转差在哪

IEPL 全称 International Ethernet Private Line（国际以太网专线），本质是在国内入口和境外出口之间点对点组一条内网通道，流量不经过公网，也就避开了公网拥堵和 QoS 限速。IPLC（国际专线）效果类似，两种名称经常被混用，实际体验差异主要体现在具体线路的端内延迟上，而不是名字本身。

MKCloud 自己的知识库有一句很实在的提醒：IEPL、IPLC、IX 是不同产品或技术名称，不能直接当作“稳定性从低到高”的排序。这句话值得记住，因为网上大量内容把“IEPL 一定吊打 IPLC”当成结论卖。

| 线路类型 | 通俗理解 | 典型端内延迟 | 接入方式 | 适合谁 |
| --- | --- | --- | --- | --- |
| IEPL | 点对点以太网专线 | 1~2ms（广港方向） | 直连，绑定一个省份 | 华南办公、电商后台 |
| IPLC | 传统国际专线 | 21ms / 25~28ms / 124~134ms（沪港/沪日/沪美） | 直连，绑定一个省份 | 上海及长三角方向业务 |
| IX（上云互联优化专线） | 从云厂网络接入的优化线路 | 深港 1~2ms | 需要支持范围内的云厂机器 | 已有阿里云/腾讯云等前置的用户 |
| 普通 BGP 中转 | 走公网优化路由 | 抖动明显，晚高峰波动 | 无特殊要求 | 预算敏感、容忍波动的场景 |

端内延迟指入口到出口在同一条专线上测得的内部延迟，不是你家到目标网站的全程延迟。你的完整体验等于“本地到入口 + 端内 + 出口到目标”三段，前一段和后一段走公网，谁也替代不了。

## 下单前先确认三件事，不合适就不用往下看了

这是 MKCloud 官方 FAQ 和知识库反复强调的部分，比选线路本身更优先。

**第一，你的业务能不能接受“只出不进”。** 这类专线 VPS 每台分配 1 个独立入口 IP 和 1 个独立出口 IP，用户连入口，在 VPS 里跑浏览器、ERP、授权 API 客户端，流量自动从出口出去。出口不接受外部连入，所以公开建站、支付回调、邮件接收、对外游戏服务端都不行。它服务的是“你在 VPS 里主动访问海外后台”这类场景。

**第二，你的接入环境符不符合。** 直连款（广港、沪港、沪日、沪美）入口一次绑定一个省份，只有该省的 IP 能连入，换地方用可以切绑省份。IX 款不限省份，但必须从支持范围内的云厂机器接入，还要把云前置机的费用算进总成本。官方对有省级白名单限制的产品有明确说明，异地团队购买前应先核对接入限制。

**第三，官方支付与售后口径。** 目前只支持支付宝付款；退款政策是仅支持质量问题退款，且需要提交具体延迟、速度数据证明；开通后不支持更换到其他地域产品。第三方测评（如知乎上的沪日测评）还提到 IPLC/IEPL 需要国内手机号实名认证，下单流程里以实际提示为准。

## 核心选购维度：看什么才知道一条 IEPL 靠不靠谱

综合 MKCloud 知识库和第三方测评的口径，判断维度其实就五个，按重要性排：

1. **端内延迟和抖动**：广港方向做到 1~2ms 属于第一梯队（第三方实测 ping 在 2~4ms 属正常波动），沪港 21ms、沪日 25~28ms 也都是明确标注的参考值。关键是商家敢不敢把这个数写出来——不写的，通常意味着不稳定。
2. **入口质量**：广港入口可选八线动态 BGP/电信/移动/联通/三线，沪方向入口为 UCloud BGP/电信。入口离你的网络越近、运营商越匹配，第一段公网路径越短。
3. **IP 形态**：MKCloud 全线是双端独立 IPv4（一入口一出口），不是共享 IP 池。对电商多账号运营来说，这决定了 IP 干净度的基础。
4. **计费方式**：共享带宽按“峰值速率 + 月流量”计费，峰值不保证持续跑满，流量按上行下行双向统计；独享带宽按配置速率计费，不限流量。两种没有绝对好坏，后面细说。
5. **附加能力**：出口对接多家国际运营商和交换中心（官方列举含 PCCW、NTT、Cogent、Telstra、Equinix IX 等），独享客户可定制路由，高防需另询价。默认套餐不含 SLA，金融级业务需要书面约定。

另外提醒一句：不要拿“能否解锁 Netflix”“是不是原生 IP”当选购标准。MKCloud 官方明确说明不保证 IP 的原生、住宅或流媒体解锁属性——这类要求本身就超出专线 VPS 的服务范围。

## 共享还是独享：一个 288 和 388 的例子讲清楚

以沪港 IPLC 为例，官方知识库给出的对照是：

- **共享入门**：1核/2GB/20GB，200Mbps 峰值，1024GB 月流量，月付 288 元（季付 864 元、年付 3456 元）。
- **独享入门**：2核/4GB/40GB，5Mbps 独享，不限流量，月付 388 元。

200Mbps 峰值和 5Mbps 独享不是同一种资源，没有谁一定快。短时间的后台操作、文件上传看重峰值，共享档合适；7×24 小时的持续传输、直播推流看重稳定速率，独享档才有意义。官方特别强调一点：**共享和独享不决定账号能否通过平台审核**，两类套餐的 IP 都是独立的，选带宽模式只看用量曲线。

还有个常被忽略的点：不限流量不等于不限速。独享档跑满 5Mbps 就是 5Mbps，想要更大持续速率就往 10M、20M、50M 档位走（广港独享档 5M ¥500/月起，100M ¥5,800/月，[👉 查看独享带宽档位](https://www.mkcloud.net/aff.php?aff=390&url=/index.php/store/gz-hk-ex)）。先记录一两周业务的真实峰值和均值，再决定买哪边，比看任何测评都准。

## 什么人不需要买 IEPL VPS

最后把不适用的情况说透，帮你省一笔冤枉钱：

- **想找翻墙机场的**：专线 VPS 是给你一台带独立 IP 的服务器跑业务，不是给手机装个 App 就能用的节点服务，两者价格和形态完全不同。
- **要公开建站或收支付回调的**：出口不接受外部连入，这条官方写得非常明确。
- **追Streaming解锁和原生 IP 的**：官方不承诺，买了大概率失望。
- **人在多省频繁切换、没有云厂机器的**：直连款绑定省份需要手动切换，IX 款又必须有支持范围内的云前置，先核对自己的接入条件再下单。
- **SLA 写进合同的金融高频业务**：默认套餐不含 SLA 保障，需要的话走工单单独询价。
